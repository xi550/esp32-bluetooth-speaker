- SDK v5.5.6（上游 commit 880a203ae603d08a94d06aa01e0d6761958e5e9e）纳入 sdk/esp-idf。
- 27 个递归子模块已展开为普通文件；导入清单共 28065 个文件，无嵌套 Git 仓库。

- 空构建目录重新生成配置通过：Classic BT/A2DP、内部解码、LCD 默认关闭、board 分区表路径均正确。
