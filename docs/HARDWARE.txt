# 硬件假设与待验证清单

以下引脚来自本次用户明确指定。当前未连接实物，不能把固件目标检查当成模组型号确认。

|用途|GPIO|约定|
|---|---:|---|
|I2S BCLK|26|两块 MAX98357A 共用|
|I2S LRCLK/WS|25|两块 MAX98357A 共用|
|I2S DOUT|22|交错立体声输出，两块功放共用 DIN|
|ST7789 SCLK|18|SPI2，初始 10MHz|
|ST7789 MOSI|23|单向写入，无 MISO|
|ST7789 CS|21|独立片选|
|ST7789 DC|19|命令/数据|
|ST7789 RST|17|面板复位|
|按键 0/1/2/3/4|13/14/27/32/33|输入、内部上拉，假设按下接地|

- [ ] 模组丝印为 ESP32-WROOM-32E/32D，不能是 S3/C3，也不能未经评估换成引脚被 PSRAM 占用的 WROVER。
- [ ] 实测 Flash 容量；默认 4MB，factory 3MB，无 OTA；若容量不同先修改默认配置和分区表。
- [ ] 五个按键电路与低有效、上拉假设一致；是否需外部上拉、RC、ESD 由硬件确认。GPIO13/14 与 JTAG 用途冲突时需重新安排调试方式。
- [ ] 两块 MAX98357A 共用 BCLK/WS/DIN，供电和逻辑电平匹配；各自 SD_MODE 电阻/电压符合对应模块/芯片资料，分别选择左与右。不得凭模块焊盘名称推断已接成立体声。
- [ ] 扬声器分别接各功放差分输出；核对负载、供电峰值和散热。初次音频验证从音源低音量开始；框架没有数字音量限制。
- [ ] 核实 I2S Philips 格式、16bit 双声道，WS=协商采样率，BCLK 对应双声道槽位；播放左右测试音确认硬件取声道。
- [ ] LCD 实际是 ST7789，确认分辨率、可视窗口偏移、RGB/BGR 顺序、方向、反色；默认 240×240、偏移0只是占位，不是硬件结论。
- [ ] 背光 BL 引脚未指定，框架不控制 BL；先确认其硬件供电/使能方式。MISO 未连接；SPI mode 0，10MHz 起步。
- [ ] 使用单 UI 任务刷新；RGB565 数据按高字节先发，准备持久有效的传输缓冲区；大缓冲区在无 PSRAM 的 WROOM 上需评估内存。
- [ ] 验证 LCD 刷新与蓝牙播放并发时的供电、吞吐、栈及堆；当前 12×2048 字节 PCM 队列并非经过实板调优。
- [ ] 测试暂停、断连、采样率切换；在途 DMA 可能留下极短尾音，尚无硬件静音、渐变或爆音抑制策略。
- [ ] 配对为无显示/无输入设备方式；量产的配对窗口、绑定管理和安全策略尚未实现。
