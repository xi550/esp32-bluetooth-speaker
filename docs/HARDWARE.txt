# 硬件假设与待验证清单

以下接线沿用用户指定的分配；背光 GPIO16 是用户授权框架分配的空闲引脚。当前未连接实物，不能把固件目标检查当成模组型号确认。

固定接线与电平入口为 board_esp_proj_cfg.h：GPIO 使用 SDK 的 GPIO_NUM_x 命名，按键逐个定义；
LCD 的 SPI 控制器、时钟、模式、RGB/BGR、坐标交换和镜像也在该文件配置。
LCD 开关、尺寸、偏移、反色、蓝牙名称及初始音量也统一在该头文件设置；menuconfig 仅管理 ESP-IDF 系统配置。
改变坐标交换后需同时核对逻辑宽高和窗口偏移；引脚数字不是模组焊盘或开发板排针序号。
框架在驱动初始化前检查启用外设的引脚冲突和能力，但不能替代实物接线与模组引出确认。

|用途|GPIO|约定|
|---|---:|---|
|I2S BCLK|26|两块 MAX98357A 共用|
|I2S LRCLK/WS|25|两块 MAX98357A 共用|
|I2S DOUT|22|交错立体声输出，两块功放共用 DIN|
|ST7789V2 SCLK|18|SPI2，40MHz，需实板验证信号质量|
|ST7789 MOSI|23|单向写入，无 MISO|
|ST7789 CS|21|独立片选|
|ST7789 DC|19|命令/数据|
|ST7789 RST|17|面板复位|
|屏幕 BLK|16|PWM 控制输入，高有效；低电平关闭，按卖家指引直接接 GPIO|
|按键 0/1/2/3/4|13/14/27/32/33|输入、内部上拉，假设按下接地|

- [ ] 模组丝印为 ESP32-WROOM-32E/32D，不能是 S3/C3，也不能未经评估换成引脚被 PSRAM 占用的 WROVER。
- [ ] 实测 Flash 容量；默认 4MB，factory 3MB，无 OTA；若容量不同先修改默认配置和分区表。
- [ ] 五个按键电路与低有效、上拉假设一致；是否需外部上拉、RC、ESD 由硬件确认。GPIO13/14 与 JTAG 用途冲突时需重新安排调试方式。
- [ ] 两块 MAX98357A 共用 BCLK/WS/DIN，供电和逻辑电平匹配；各自 SD_MODE 电阻/电压符合对应模块/芯片资料，分别选择左与右。不得凭模块焊盘名称推断已接成立体声。
- [ ] 扬声器分别接各功放差分输出；核对负载、供电峰值和散热。初次音频验证从音源低音量开始；主音量默认 16/50 档，手机可覆盖，不构成硬件最大音量限制。
- [ ] 核实 I2S Philips 格式、16bit 双声道，WS=协商采样率，BCLK 对应双声道槽位；播放左右测试音确认硬件取声道。
- [ ] 用户已确认 LCD 控制器为 ST7789V2，确认分辨率、可视窗口偏移、RGB/BGR 顺序、方向、反色；用户已确认 1.69 英寸、240×280；偏移0仍是占位，需依据实际模组确认。
- [ ] 用户转述卖家说明：BLK 为背光开关，默认打开、低电平关闭，接线指引为 GPIO 接 BLK。分配 GPIO16，屏幕与 ESP32 共地；20kHz PWM 的实际调光效果仍需验证。MISO 未连接；SPI mode 0，40MHz；若出现花屏或不稳定，应降低时钟并检查接线。
- [ ] 使用单 UI 任务刷新；RGB565 数据按高字节先发，准备持久有效的传输缓冲区；大缓冲区在无 PSRAM 的 WROOM 上需评估内存。
- [ ] 验证 LCD 刷新与蓝牙播放并发时的供电、吞吐、栈及堆；当前 12×2048 字节 PCM 队列并非经过实板调优。
- [ ] 测试暂停、断连、采样率切换；在途 DMA 可能留下极短尾音，尚无硬件静音、渐变或爆音抑制策略。
- [ ] 配对为无显示/无输入设备方式；量产的配对窗口、绑定管理和安全策略尚未实现。

背光配置统一在 cfg.h：BOARD_LCD_BL_PIN=GPIO_NUM_16、BOARD_LCD_BL_ACTIVE_LEVEL=1、
BOARD_LCD_BL_PWM_HZ=20000、BOARD_LCD_BL_PWM_BITS=10、BOARD_INITIAL_BRIGHTNESS=60。
GPIO16 仅用作模块 BLK 控制信号，屏幕供电仍接其指定电源端；不要把 GPIO 当作屏幕供电。
软件初始化后先关闭背光，LVGL 首帧发送完成后设为 60%，0 关闭、100 常亮。
LEDC 低速组的定时器 0、通道 0 由背光独占；PWM 频率和亮度不保存在 NVS。
